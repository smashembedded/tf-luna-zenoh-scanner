# Hardware

## Overview

The TF-Luna Zenoh Scanner is built around an ESP32 development board connected to a Benewake TF-Luna LiDAR and a servo motor.

The servo rotates the LiDAR around a single axis, allowing the system to acquire a 2D angular scan.

## ESP32

The embedded controller is based on an ESP32-DevKitC V4 development board using the ESP32-WROOM-32D module.

The ESP32 provides:

- Main application processing
- Wi-Fi connectivity
- UART communication with the TF-Luna
- PWM generation for servo control

The ESP32-WROOM-32D operates from a 3.0–3.6 V supply, with 3.3 V nominal operation.

## TF-Luna

The Benewake TF-Luna is used as the distance sensor.

The sensor supports:

- 5 V supply
- UART communication
- I²C communication

The initial implementation will use UART for communication with the ESP32.

## Servo

The scanner uses a Tower Pro Micro Servo 9g SG90 to rotate the TF-Luna.

The servo is controlled using a PWM signal generated by the ESP32.

The servo must be powered from an appropriate power supply rather than directly from an ESP32 GPIO.

## Power

The final power distribution depends on the selected external power supply.

The power supply must provide the voltage and current required by the connected peripherals.

The servo should not be powered directly from an ESP32 GPIO.

The ESP32 and the externally powered peripherals must share a suitable common ground for the control and communication signals.

## Pin Assignment

The initial prototype uses the following ESP32 pins:

| ESP32 GPIO | Function | Connected device |
|---|---|---|
| GPIO16 | UART2 RX | TF-Luna TX |
| GPIO17 | UART2 TX | TF-Luna RX |
| GPIO18 | PWM | SG90 signal |
| GND | Ground | TF-Luna and servo ground |

The pin assignment is selected to keep the sensor UART and servo PWM independent.

### SG90

| SG90 | Connection |
|---|---|

| GND | Common GND |

The external servo supply and ESP32 must share a common ground.

The exact external power supply specification will be documented once the power source is selected.

## Safety and electrical considerations

- Do not power the servo directly from an ESP32 GPIO.
- Verify the operating voltage of every component before connecting the hardware.
- Ensure that the external power supply can provide the required servo current.
- Ensure that the ESP32 and externally powered peripherals share a suitable common ground.
- Double-check polarity before powering the system.

## Reproducibility

The hardware configuration should be reproducible using the component models, electrical specifications and wiring diagram documented in this repository.
